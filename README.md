# Hysteria2
    Hysteria2 - Легкий и малозатратный инструмент для сетевой работы.

    ## **😇 Руководство по использованию**:
    ☆ Этот скрипт сократит потребность в поддержке обновлений (особенно в ранних этапах). В дальнейшем будет доступна версия на Python, которая будет поддерживать большинство функций.

    ☆ Выполните команду на сервере для установки.

    ☆ Подходит для большинства систем, однако рекомендуется использовать Debian/Ubuntu.

    ☆ Если у вас есть домен, используйте acme для получения сертификатов, в противном случае используйте самоподписанный сертификат.

    ☆ Скрипт поддерживает несколько типов ПО, указанных ниже.

    ☆ Просто запустите скрипт, чтобы все настроить.

    ☆ Поддержка установки ядра Xanmod с использованием ускорения BBRv3 (скрипт взят с [ylx2016](https://github.com/ylx2016/Linux-NetSpeed)).

    **Онлайн-конвертер подписок** (поддерживает преобразование между несколькими протоколами): [Конвертировать подписки](https://sub.crazyact.com/)

    **🙃 Скрипт установки (Shell версия)**:
    ```
    wget -O install.sh https://raw.githubusercontent.com/seagullz4/hysteria2/main/install.sh && chmod +x install.sh && bash install.sh
    ```
    **🙃 Скрипт установки (Python версия, рекомендуется)**:
    ```
    # Сначала установите зависимости:
    wget -O phy2.sh https://raw.githubusercontent.com/seagullz4/hysteria2/main/phy2.sh && chmod +x phy2.sh && bash phy2.sh

    # Затем выполните основной установочный скрипт:
    wget -O hy2.py https://raw.githubusercontent.com/seagullz4/hysteria2/main/hysteria2.py && chmod +x hy2.py && python3 hy2.py
    ```

    **Для удобства добавлен ярлык для терминала**: используйте команду `hy2` для автоматического выполнения скрипта.
